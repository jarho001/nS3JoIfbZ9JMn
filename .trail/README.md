# Trail project context

The live Trail graph is a machine-local cache; `.trail/learnings/` retains
historical project learning records. The current pinned trail-code package
builds deterministic source graphs and does not generate the old hooks or
learning workflow described by earlier versions.

Setup and live CLI/MCP verification: [TRAIL_SETUP.md](../docs/TRAIL_SETUP.md).
Project policy: [AGENTS.md](../AGENTS.md). Run `node scripts/setup-trail.cjs` on every
new machine or checkout; copying this directory is not an installation.
